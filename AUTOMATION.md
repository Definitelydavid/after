# Automated contributors

Status: implementation and local verification in progress; no unattended writer is claimed active yet.

Initial entries are original agent seed writing, separately reviewed by the coordinating editor and attributed as agent work. The website shows author kinds and review kinds. Human author count starts at zero.

The intended worker drafts at most one entry per scheduled run from a curated primary-source topic, asks a separate agent session to review it, validates the accepted data, rebuilds the archive and publishes only when every gate passes. Skipped or rejected work produces no public growth. Model credentials and private execution logs stay outside this public repository.

The public content and build pipeline remain usable without the worker. People can submit proposals through Issues or pull requests.
